# CAD Copilot v0.1.0 — Windows Preview

The first public Windows x64 installer bundles the desktop app and Python engine. A local Siemens Solid Edge installation is required; developer toolchains are not required to try the app.

## Try it

1. Download [CAD-Copilot_0.1.0_x64-setup.exe](https://github.com/jitendra-patwari/cad-copilot/releases/download/v0.1.0/CAD-Copilot_0.1.0_x64-setup.exe) and [SHA256SUMS.txt](https://github.com/jitendra-patwari/cad-copilot/releases/download/v0.1.0/SHA256SUMS.txt), then verify the installer hash using [Getting Started](https://github.com/jitendra-patwari/cad-copilot/blob/main/docs/getting-started.md).
2. Install and open CAD Copilot from the Windows Start menu. Start with the key-free **Example (Spur Gear)**.
3. For **Prompt to CAD**, follow [Gemini API Key Setup](https://github.com/jitendra-patwari/cad-copilot/blob/main/docs/gemini-api-key.md). An eligible free-tier Google AI Studio project can be used; review current quotas and data terms.

Siemens offers [Solid Edge Community Edition](https://github.com/jitendra-patwari/cad-copilot/blob/main/docs/solid-edge-community-edition.md) for personal, non-commercial use. Separate qualification of every export format on that edition remains open.

## Included

- Native Ordered-mode part generation with PAR, STEP, STL, a best-effort JPG preview, and a verified run manifest.
- Key-free conceptual gear example and optional Gemini prompt interpretation.
- Reliable active-window preview capture and a **Keep part open in Solid Edge** checkbox, unchecked by default.
- Native-file batch export, drawing publication, progress, cancellation, and verified manifests.
- Per-user installation, bundled engine dependencies, and third-party notices.

## Preview boundaries

Review prompt-generated dimensions, features, faces, and saved geometry before use. The gear outline is illustrative and is not a manufacturing-qualified gear. JPG previews are best effort; a preview warning does not invalidate successful CAD exports. Gemini sends prompt text to Google using an in-memory session key; CAD files and exports stay local. Solid Edge is supplied and licensed separately.
